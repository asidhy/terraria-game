# 泰拉瑞亚风格 2D 沙盒生存游戏

纯 **HTML5 Canvas + 原生 JavaScript** 实现，零第三方依赖，双击 `index.html` 即可运行。

对应赛题：**赛题 3 · 码道开发泰拉瑞亚风格 2D 沙盒游戏**。

## 运行

```bash
# 方式一：直接用浏览器打开
start index.html

# 方式二：起本地服务（避免 file:// 限制）
npx serve .
```

## 自动化验证

```bash
node --check game.js     # 语法检查 → SYNTAX OK
node test-headless.js    # 无头冒烟测试：模拟 600 秒 → SMOKE OK: 600s 模拟无异常
```

`test-headless.js` 用 vm 沙箱 + 桩对象替代 DOM/Canvas，把游戏逻辑从浏览器里剥出来跑，
覆盖世界生成、600 秒主循环（含完整昼夜与僵尸生成/自燃）、挖掘、放置、合成、战斗。

## 操作

| 按键 | 功能 |
|------|------|
| A / D | 左右移动 |
| 空格 / W | 跳跃 |
| 鼠标左键 | 挖掘（持镐）/ 放置（持方块）/ 攻击（持剑） |
| 滚轮 / 1~0 | 切换快捷栏 |
| E | 背包与合成（自动尝试可合成的下一件物品） |

## 已实现的特性

- **随机地形**：1D 噪声定地表高度 → 2D fbm 掏洞穴 → 随机游走画矿脉 → 概率种树
- **挖掘与建造**：13 种图块，镐分级（木 → 石 → 铁 → 金），方块自由放置
- **合成系统**：工作台、火把、四档镐、四档剑；石镐及以上需要靠近工作台
- **昼夜交替**：日月起落、星空、天色渐变、火把光晕照明
- **僵尸 AI**：夜间在屏幕外生成、追踪玩家、遇墙跳跃、接触伤害、掉落金币、天亮自燃
- **泰拉瑞亚式 HUD**：红心生命条、10 格快捷栏、金币计数、天数与昼夜指示

## 代码结构

| 文件 | 说明 |
|------|------|
| `index.html` | 页面骨架 + Canvas 容器 |
| `game.js` | 游戏全部逻辑（约 1000 行） |
| `test-headless.js` | 无头冒烟测试 |

`game.js` 内部分模块：

| 模块 | 内容 | 关键思路 |
|------|------|----------|
| 常量与图块 | `T` 枚举 13 种图块，`TILEINFO` 定义硬度/所需镐/掉落物/是否阻挡 | 数据驱动，加新方块只需加表项 |
| 噪声 | `hash1` / `hash2` / `noise1` / `noise2` / `fbm` | 哈希 + 平滑插值 + 分形叠加，无需外部库 |
| 世界生成 | `genWorld()` / `veins()` | 1D 噪声定地表 → 2D 噪声掏洞穴 → 随机游走画矿脉 → 概率种树 |
| 物理 | `collides()` / `moveEntity()` | AABB 与图块网格碰撞，先 X 后 Y 分轴解算，避免斜向穿墙 |
| 挖掘/放置/攻击 | `mineAt()` / `placeAt()` / `attack()` | 手持物决定左键行为；镐等级不足时给出提示 |
| 僵尸 AI | `spawnZombie()` / `updateZombies()` | 夜间屏幕外生成，朝玩家移动，遇墙跳跃，天亮自燃 |
| 光照 | `drawDarkness()` | 离屏 canvas 铺暗色遮罩，再用 `destination-out` 径向渐变挖亮（天空光 + 火把 + 玩家微光） |
| 渲染 | `drawTile()` / `drawHumanoid()` / `drawHud()` | 哈希驱动的伪随机纹理像素；矩形拼装角色 |
| 合成 | `RECIPES` / `canCraft()` | 配方表 + 材料检查 + 工作台 proximity 检测 |
| 主循环 | `loop()` | 固定上限时间步（dt 上限 0.05s，防切后台大跳）+ 每帧渲染 |

## 无头测试怎么做到的

浏览器游戏最大的问题是逻辑与 DOM/Canvas 强耦合。这里的做法是：

1. `game.js` 用 IIFE 包裹，从 `window.__game` 暴露纯逻辑 API（`update` / `craft` / `mine` / `getState` …）
2. 检测到 `window.__HEADLESS__ === true` 时，跳过 canvas 初始化、事件绑定和 `requestAnimationFrame`
3. `test-headless.js` 造一个 `vm` 沙箱当 `window`，把 `game.js` 跑进去，然后自己按 1/60 秒步长推 36000 步

副作用被关进笼子，只验证逻辑——这是测试 UI 密集型代码的常见思路。
